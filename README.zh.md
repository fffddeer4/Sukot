# Sukot VPN

[![en](https://img.shields.io/badge/lang-EN-blue)](README.md) · [![fa](https://img.shields.io/badge/lang-FA-blue)](README.fa.md)

**Sukot** 是一款快速、免费且美观的 VPN：一键连接、带真实延迟的服务器列表、支持 `vmess` / `vless` / `trojan` / `ss` / `hysteria2` 配置导入（主页的 + 按钮）、Windows 版本以及完整的波斯语界面。
