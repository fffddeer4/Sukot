# Sukot VPN (فیلترشکن سوکوت)

[![en](https://img.shields.io/badge/lang-EN-blue)](README.md) · [![fa](https://img.shields.io/badge/lang-FA-blue)](README.fa.md)

**سوکوت** یک فیلترشکن سریع، رایگان و زیباست: یک ضربه برای اتصال، لیست سرورها با پینگ واقعی، پشتیبانی از کانفیگ‌های `vmess` / `vless` / `trojan` / `ss` / `hysteria2` (دکمه + در صفحه اصلی)، نسخه ویندوز و رابط کاربری کاملاً فارسی.
