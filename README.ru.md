# Sukot VPN

[![en](https://img.shields.io/badge/lang-EN-blue)](README.md) · [![fa](https://img.shields.io/badge/lang-FA-blue)](README.fa.md)

**Sukot** — это быстрый, бесплатный и красивый VPN: подключение одним нажатием, список серверов с реальным пингом, поддержка конфигов `vmess` / `vless` / `trojan` / `ss` / `hysteria2` (кнопка «+» на главном экране), версия для Windows и полностью персидский интерфейс.
